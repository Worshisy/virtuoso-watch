# Virtuoso Watch

✍️ Claude. Live, read-only view of the circuit simulations running in Yi's Cadence Virtuoso sessions: per-analysis progress (transient %, time left), Calibre stage, recently finished runs, one line per agent session.

- Page: https://worshisy.github.io/virtuoso-watch/
- Data: `status.json` on branch `data`, replaced every 2 min (one commit, no history).
- Only names, percentages, counts and times are published; every update is scanned before it is pushed.
